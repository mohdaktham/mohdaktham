## Featured project: Tessera

[![Tessera dashboard](https://raw.githubusercontent.com/mohdaktham/tessera/main/docs/screenshots/dashboard-dark.png)](https://github.com/mohdaktham/tessera)

A SQL workbench that runs in the browser and as a desktop app. Import CSV, JSON or SQLite files, query them with SQL, chart the results and pin them to a live dashboard. Your data never leaves your machine.

- **Stack:** TypeScript, React, Electron, SQLite compiled to WebAssembly, Tailwind CSS
- **Engineering:** queries run off the main thread, sandboxed desktop shell, strict content security policy
- **Quality:** unit, component and end-to-end tests, run on Windows, macOS and Linux on every push

**[Open the live site](https://tesserasql.vercel.app/)** · **[Source code](https://github.com/mohdaktham/tessera)** · **[Download](https://github.com/mohdaktham/tessera/releases)**
